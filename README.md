# The Escalante Loop — Website Analysis & Redesign Proposal

A website analysis and redesign proposal created for The Escalante Loop, a community-focused business organization in Escalante, Utah. This project evaluated the existing website experience and provided recommendations to improve usability, branding consistency, navigation, accessibility, and visitor engagement.

## Overview

This project was developed as a website consultation and redesign proposal for The Escalante Loop. The organization requested feedback on its website, and I conducted a usability review focused on identifying opportunities to improve navigation, branding, mobile accessibility, and overall user experience.

The goal was to provide practical recommendations that would better support local businesses, community engagement, event promotion, and space rental opportunities.

## Research & Evaluation Process

The analysis was conducted through a manual review of the existing website experience, including:

* Navigation and information architecture evaluation
* Mobile usability review
* Visual design and branding assessment
* Accessibility observations
* Content organization analysis
* User journey evaluation for business discovery, event participation, and rental inquiries

Findings were compiled into a presentation containing prioritized recommendations, redesign concepts, and implementation considerations.

## Project Goals

The primary goals of the redesign proposal were to:

* Create a stronger and more cohesive brand identity
* Simplify navigation for visitors
* Improve mobile usability
* Increase visibility for local businesses
* Add a clear rental inquiry process
* Modernize the overall website experience

## Key Recommendations

### Navigation Simplification

The existing website contained too many navigation items, making it difficult for visitors to quickly find important information.

Proposed improvements:

* Streamlined navigation
* Simplified page hierarchy
* Consistent global header and footer

### Mobile-Friendly Design

The original website was not fully optimized for mobile visitors.

Recommendations included:

* Responsive layouts
* Improved readability
* Mobile-first design considerations

### Brand Identity System

A cohesive visual direction was proposed using:

* Consistent typography
* Earth-toned color palettes inspired by the Escalante landscape
* Improved visual consistency across all pages

### Business Showcase

Recommended creating dedicated business cards and cleaner layouts for:

* Business information
* Hours
* Booking/contact actions
* Individual business pages

### Event Experience

Suggested redesigning the events section using:

* Event cards
* Clear date formatting
* Better readability
* Easier content updates
